# 秋招网申状态巡检器（patrol/）

自动读取你已投递公司的校招官网后台状态（简历筛选 / 待测评 / AI面试 / 笔试 /
面试 / 通过 / 已挂），写入本地看板 `dashboard/application_status.json`，
打开 dashboard.html 就能直接看到，不用再手动刷官网。

## 快速开始（两步）

1. **保存登录态（只做一次）**：双击 `login.bat`，会依次弹出每个公司官网的
   真浏览器窗口，你正常扫码/登录，看到登录成功后回命令行按 Enter。
   登录态保存在本机 `patrol/.secrets/profiles/`，不会上传任何地方。
   - 可以分批做：`python login.py 腾讯 美团 百度`（支持名称片段）
2. **启动巡检**：双击 `start_patrol.bat`（常驻模式，每 ≥4 小时自动巡检一轮，
   关闭窗口即停止）。打开 `http://localhost:8420/dashboard.html`，
   首页"投递状态巡检"面板会显示结果。

其他入口：
- `check_now.bat`：立即巡检一轮（无视 4 小时保护，请节制）
- `python patrol.py --companies 腾讯,美团`：只查指定公司
- `python patrol.py --headed`：有头模式排查问题

## 工作原理与反风控设计

- 基于 Playwright（Chromium）+ 关键词窗口匹配提取状态，**不需要你找任何
  XPath/选择器**；网站改版大概率不受影响
- 两次巡检**强制间隔 ≥4 小时**（+0~20 分钟随机抖动），`--force` 才能越过
- 公司之间随机等待 8~18 秒；顺序访问；每次只看自己的申请页，绝不批量爬取
- 落地页不显示状态时，自动尝试点击"我的投递 / 申请进度 / 我的状态"等文字链接
- 识别不到状态时自动截图存 `patrol/screenshots/`、页面文本存
  `patrol/.secrets/captures/`，供人工核对（这就是"需人工核对"标记的来源）

## 重要提醒（务必读）

- **本工具仅作个人秋招备忘**：只巡检你本人已投递的账号后台，不保证 100%
  通过所有网站的登录校验，**不承担任何账号风控风险**
- 登录态失效时面板会显示"未登录"，重新跑一次 `login.bat 该公司` 即可
- 所有数据（Cookie、截图、状态）只保存在本机；**不要把 `patrol/.secrets/`
  分享给任何人、不要上传网盘/Git**
- 个别公司暂时显示"未配置"，是因为还没找到它的校招系统入口——在
  `config.json` 里把该公司的 `login_url` 补上即可（或让 AI 帮你补）
- 若某平台明确禁止自动化访问，请把它的 `enabled` 改为 `false`
